# Интерфейс для отправки и получений сообщений WhatsApp

**Запуск dev-режима:**
`npm run dev`

**Запуск build-режима:**
`npm run build`

**Deploy проекта:**
`npm run deploy`

### Стек технологий:
1) React + Typescript;
2) Стили: CSS Modules;
3) REST API: [GreenApi](https://green-api.com/docs/api/);
4) Линтирование: ESLint;
5) Архитектура: [FSD](https://feature-sliced.design/);
6) Сборщик: Vite.

# Сохранение данных пользователя
Данные пользователя в рамках данного проекта сохраняются в LocalStorage

# Состояниe
Для хранения состояния используется Context

# Для использования приложения необходимо выполнить следующие шаги:

1) Установить мобильное приложение WhatsApp
2) Регистрация в [Личном кабинете](https://console.green-api.com/registration) Green-api
   Инструкция:

    2.2 Введите электронную почту.
    2.3 Введите пароль и подтвердите его. Длина пароля должна быть не менее 6 символов.
    2.4 Выберите страну.
    2.5 Приняв пользовательское соглашение, нажмите на кнопку Зарегистрироваться.
    2.6 На Ваш адрес электронной почты будет направлено письмо. Введите код, указанный в письме, для подтверждения вашей учетной записи.

3) Создание и авторизация инстанса.
   Инстанс - это уникальный номер шлюза для отправки и получения сообщении через WhatsApp.Инстанс создается в личном кабинете и используется для организации HTTP API WhatsApp.

   Порядок создания инстанса:

    3.1 В [личном кабинете](https://console.green-api.com/registration) нажмите на кнопку Создать инстанс.
    3.2 Выберите тарифный план(developer)
    3.3 Перейдите в список инстансев, нажав на кнопку Инстансы в боковом меню. В списке можете увидеть созданный вами инстанс.
    3.4 Переход инстанса в рабочее состояние после создания может занимать до 2-х минут.

    Авторизация инстанса

    Для работы с GREEN-API требуется авторизовать инстанс. Авторизация инстанса выполняется в [Личном кабинете](https://console.green-api.com/registration) путем считывания QR-кода из мобильного приложения WhatsApp Business или WhatsApp.

    Порядок авторизации инстанса:

    3.1 Откройте на своем мобильном телефоне приложение WhatsApp Business или WhatsApp. На устройстве перейдите в раздел 3.2 Привязка устройства, для этого:
    3.3 На Android нажмите на 3 точки - Связанные устройства - Привязка устройства
    3.4 На iPhone перейдите в Настройки - Связанные устройства - Привязка устройства
    3.5 Перейдите в [личный кабинет](https://console.green-api.com/registration) . Выберите нужный вам инстанс.
    3.6 Нажмите на кнопку Получить QR. Отсканируйте QR код.

4) Получить параметры доступа к инстансу
    Для выполнения запросов HTTP API WhatsApp требуется использовать параметры доступа к инстансу. Параметры доступа публикуются в [личном кабинете](https://console.green-api.com/registration):

    apiUrl - ссылка на хост API
    mediaUrl - ссылка на хост API для отправки файлов
    idInstance - уникальный номер инстанса
    apiTokenInstance - ключ доступа инстанса

5) Настроить получение входящих данных
    Настройку получения входящих уведомлений можно также выполнить интерактивно. Для этого перейдите в [Личный кабинет](https://console.green-api.com/registration) и выберите требуемый инстанс. Будут отображены текущее состояние инстанса и настройки для получения входящих уведомлений. Что бы поменять настройки необходимо нажать кнопку изменить на панели инстанса. Текущие настройки можно будет поменять на панели уведомлений см. рис. Укажите значение параметра webhookUrl, а также переключатели по видам уведомлений. Нажмите на кнопку "Сохранить изменения" для применения настроек.
